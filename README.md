# Literalura

Literalura es una aplicación construida con Java y Spring Boot que permite consultar libros desde la API de [Gutendex](https://gutendex.com), almacenarlos en PostgreSQL, y consultarlos mediante una API REST.

---

## ¿Qué hace?

- Consulta libros por título en la API de Gutendex
- Guarda libros y autores en base de datos
- Evita duplicados
- Lista libros y autores guardados
- Lista autores vivos en un año determinado
- Lista libros por idioma

---

## Tecnologías

- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
